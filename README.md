# AI Advisor Ultra 6.5 — Neural Scanner + Smart Tools

واجهة ثابتة تعمل بالكامل في المتصفح وقابلة للنشر على GitHub Pages، تجيب عن ثلاثة أسئلة:
ما حالة جهازي؟ ما النماذج المثبّتة عليه فعلاً؟ وما الذي أحتاج ترقيته لتشغيل نموذج معيّن؟

## الجديد في v6

**فحص الجهاز (تبويب «فحص الجهاز»)**
- قياس فعلي لأداء النواة الواحدة والأنوية المتعددة عبر Web Workers
- قياس نطاق الذاكرة، وقياس حساب الرسوميات بشادر WebGPU حقيقي
- اختبار ثبات حراري لخمس ثوانٍ يكشف كم ينخفض الأداء تحت الحمل المستمر
- قراءة محوّل WebGPU وحدوده، وWebGL، وحصة القرص، وتثبيت التخزين، والبطارية، والشبكة
- تدقيق قدرات المتصفح: SIMD، خيوط WASM، العزل عبر المصادر، OPFS، WebNN
- تقرير حالة يذكر كل مشكلة تعيق التشغيل المحلي مع طريقة إصلاحها، وتصدير التقرير JSON

**اكتشاف النماذج المثبّتة (تبويب «نماذجي المثبتة»)**
- فحص متوازٍ لـ ١٤ خادماً محلياً على localhost و127.0.0.1:
  Ollama، LM Studio، llama.cpp/llamafile، Jan، LocalAI، vLLM، KoboldCpp،
  Text Generation WebUI، GPT4All، Docker Model Runner، ComfyUI، SD WebUI، Open WebUI، AnythingLLM
- لكل نموذج: الحجم، التكميم، العائلة، السياق، البصمة، تاريخ التحديث، وهل هو محمّل في الذاكرة الآن وكم منه على كرت الرسوميات
- تفاصيل المعمارية من بطاقة النموذج: عدد الطبقات، رؤوس الانتباه وKV، بعد التضمين، القدرات، الرخصة
- قياس السرعة الحقيقية (رمز/ثانية) ومقارنتها بالتقدير النظري
- إدارة Ollama: تنزيل بنسبة تقدم، حذف، إخراج من الذاكرة، تعيين النموذج للدردشة
- قراءة ذاكرة الرسوميات الحقيقية من ComfyUI واعتمادها في الحسابات
- كشف نماذج WebLLM و transformers.js المخزّنة داخل المتصفح وحجمها
- دليل إعداد عملي عند عدم العثور على أي خادم (بما فيه ضبط OLLAMA_ORIGINS)

**مستشار الترقية (تبويب «مستشار الترقية»)**
- محرك يحسب لكل نموذج: حجم الأوزان + ذاكرة السياق + حمل التشغيل حسب التكميم وطول السياق
- حكم لكل نموذج على جهازك مع سرعة متوقعة وسبب الرفض إن وُجد
- ما ينقصك بالضبط: كم غيغابايت ذاكرة، أو أي حجم ذاكرة كرت، أو تكميم أخف، أو سياق أقصر
- إدخال يدوي للمواصفات الحقيقية لأن المتصفح يبلّغ ٨ غيغابايت كحد أقصى
- محاكي «ماذا لو» يعرض عدد النماذج التي ستُفتح قبل الشراء
- ثلاثة مسارات ترقية مرتبة بالتكلفة مع ما يفتحه كل مسار

## البنية
- `index.html` — الواجهة والأنماط
- `app.js` — النواة السابقة: الدردشة، RAG، OCR، WebLLM، الإنجازات
- `ultra.js` — وحدة v6: الفحص العميق، اكتشاف النماذج، مستشار الترقية
- `ultra-tools.js` — وحدة v6.5: الأدوات الذكية العشر
- `sw.js` — عامل الخدمة (لا يمر عبر الكاش أي طلب لخادم محلي)
- `manifest.json` — إعدادات PWA

## النشر
ارفع الملفات الستة إلى المستودع ثم فعّل GitHub Pages.

**ملاحظة مهمة:** اكتشاف النماذج المحلية يحتاج أن تُفتح الصفحة عبر `http://localhost`
أو من ملف محلي، لأن المتصفح يحجب طلبات HTTP المحلية القادمة من صفحة HTTPS.
وفي Ollama اضبط `OLLAMA_ORIGINS=*` قبل التشغيل حتى يسمح للصفحة بالوصول.
